# 《第一份工作，只是起点》完整30页交付测试

本目录为 guizang Skill 原生 HTML 演示稿，共30页、7章，清华紫浅底学术简约风格。计划讲述45分钟，另留5分钟机动。不是PPTX文件。

## 打开与演讲

1. 用桌面浏览器打开本目录中的 `index.html`。不要只单独移动HTML文件；`images/` 与 `assets/` 必须随行。
2. 使用左右方向键翻页，点击顶部章节气泡跳转；封面无顶部导航。
3. 按 `ESC` 进入页面总览。按 `P` 进入演讲者模式；需要观众窗口时允许浏览器弹窗。
4. 演讲者模式包含当前/下一页预览、备注、计时、排练和演前检查。备注计划总计45分钟。
5. 按 `B` 切换静态/动态。若现场网络不稳定，正文已有系统中文字体回退、页面图标内联和本地Motion文件；外部字体与公共界面图标仍有CDN依赖，不能据此宣称全部功能完全离线。
6. 图片来源链接需要联网。生成插图均标明示意；数据脚注和来源记录与稿件一并保留。

## 主要文件

- `index.html`：完整演示稿。
- `演讲备注.json`：与页面ID一一对应的演讲提示。
- `来源与口径.json`：数据、原文、访谈来源与边界。
- `逐页交付索引.json`：30页标题、布局选择、图片处理、时长。
- `workflow/pages/`：每页独立输入、三路检索、语义选择、图片判断及检查记录。
- `validation/`：静态校验原始结果。

- `交付清单.json`：包内文件大小和SHA-256，便于核对搬运完整性。
